# OpenCtrl / Examples

Concrete examples live here. Keep examples focused on a specific input surface or interaction pattern, and put reusable platform code in `../Source`.

## Examples

- `CurlController`: shell scripts that send keyboard, mouse, and gamepad requests to a running core.
- `WebController`: browser-based driving controls.
- `Steering001Controller`: steering wheel prototype using the XIAO ESP32S3 core shape plus steering-specific sensor code.
